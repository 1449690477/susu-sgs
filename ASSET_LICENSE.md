# Visual asset attribution

The visual files under `sgs_assets/` were obtained from the open-source
[libccy/noname](https://github.com/libccy/noname) project.

- Upstream license: GNU General Public License v3.0
- Upstream asset locations: `image/card/`, `image/character/`,
  `theme/style/cardback/image/official.png`, and `image/background/noname_bg.jpg`
- Retrieval/mapping implementation in the MaiBot workspace:
  `deploy/sgs_pages/fetch_assets.py`
- `huosha.png` and `leisha.png` reuse `sha.png`; `zixing.png` reuses
  `zhuahuang.png` because the corresponding upstream artwork was unavailable.

The full GPL-3.0 text is included in `LICENSE.assets.GPL-3.0.txt`.
